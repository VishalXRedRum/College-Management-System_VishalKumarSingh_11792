🎓 College Management System
📌 About the Project

The College Management System is a console-based Java application developed to organize basic student information and demonstrate the practical implementation of Object-Oriented Programming (OOP) concepts and commonly used data structures.

The project uses different Java data structures to handle various college management operations efficiently. It provides a simple educational model of how data can be stored, accessed, processed, and managed in a college environment.

🚀 Features
Student Management: Maintains student records using ArrayList.
Record Operations: Uses LinkedList to support student record operations.
Request Processing: Implements a Queue to process administrative requests in First-In-First-Out (FIFO) order.
Activity Tracking: Uses a Stack to track recent actions in Last-In-First-Out (LIFO) order.
Course Relationships: Represents relationships between courses or subjects using a Graph.
Console-Based Interface: Provides a simple command-line environment for interacting with the system.

Navigate to the project directory:

Open the project in your preferred Java IDE.
Compile and run the main Java class.
